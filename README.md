🧠 Python Basics – Practice Programs
This folder contains beginner-friendly Python programs covering conditional statements, dictionaries, and file handling.

1️⃣ Grade Checker
Description:
Takes a score as input and prints the grade based on the marks.
Logic Used:
if-elif-else conditions to determine the grade.
Grading Rules:
Score	Grade
90+	A
80–89	B
70–79	C
60–69	D
Below 60	F

2️⃣ Student Grades
Description:
Uses a dictionary to store and manage student names and grades.
Allows the user to:
Add a new student and grade
Update an existing grade
Display all student grades
Logic Used:
dictionary for data storage
if-else and loops for options

3️⃣ Write to a File
Description:
Creates a text file and writes sample content to it using:
with open('filename.txt', 'w') as f:
    f.write("Your text here")
Mode Used: 'w' → write mode (creates/overwrites file)
4️⃣ Read from a File

Description:
Reads the content from a text file and displays it on the console using:
with open('filename.txt', 'r') as f:
    print(f.read())
Mode Used: 'r' → read mode.

🧩 Concepts Covered
Conditional Statements (if, elif, else)
Dictionaries and Loops
File Handling (open, read, write, with block)
User Input and Output
